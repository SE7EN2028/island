# Island

A Dynamic Island for your Mac's notch: music with live lyrics, a lock-screen player, clipboard history, Claude Code, Codex and Cursor status, timers and more. Native AppKit, no web views.

**Website:** https://island-notch-mac.vercel.app

## Download

Get the latest version from [Releases](https://github.com/SE7EN2028/island/releases/latest), or directly: [Island.zip](https://github.com/SE7EN2028/island/releases/latest/download/Island.zip)

1. Unzip it and drag **Island** into your Applications folder.
2. Open it. If macOS says it can't check the developer, open **System Settings › Privacy & Security**, scroll down and click **Open Anyway**.

Every feature is free for 30 minutes. A license is $9.99 once (₹349 in India) and works on 2 Macs.

Requires macOS 14 Sonoma or later, Apple silicon or Intel.

This repository only hosts the downloads.
